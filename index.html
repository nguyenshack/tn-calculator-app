Cách cài đặt

Chỉ 4 bước đơn giản để bắt đầu sử dụng

1

Tải file ZIP

Nhấn nút "Tải ứng dụng (.zip)" ở trên để tải file về máy tính.

2

Giải nén

Giải nén file ZIP vừa tải. Bên trong là mã nguồn dự án Android (Kotlin + Gradle).

3

Mở bằng Android Studio

Mở thư mục đã giải nén bằng Android Studio. Chờ Gradle sync hoàn tất.

4

Build & Cài đặt

Nhấn Run ▶ để build APK và cài trực tiếp lên điện thoại qua USB hoặc tạo file APK.

Lưu ý quan trọng

Nếu máy bạn đã cài bản TN-001 cũ được ký bằng chữ ký số khác (ví dụ bản từ nguồn khác), bạn cần gỡ bản cũ trước khi cài bản mới. Việc gỡ cài đặt sẽ xóa toàn bộ dữ liệu cũ (lịch sử tính toán, biến đã lưu…). Hãy sao lưu nếu cần trước khi gỡ. Để build từ mã nguồn, bạn cần cài Android Studio và JDK 17+.

File ZIP được phân phối trực tiếp từ GitHub Releases của nhà phát triển. Mã nguồn hoàn toàn mở, bạn có thể kiểm tra toàn bộ code trước khi build. File được ký điện tử để đảm bảo tính toàn vẹn.
Android mặc định chỉ cho phép cài app từ Google Play. Vì TN-001 được phân phối qua file APK (ngoài Play Store), bạn cần bật tùy chọn này một lần cho trình duyệt hoặc trình quản lý file mà bạn dùng để mở file APK. Đây là thiết lập bình thường và an toàn.
Lỗi này xảy ra khi máy bạn đã có sẵn bản TN-001 cũ được ký bằng chữ ký số khác. Cách xử lý:

1. Vào Cài đặt → Ứng dụng → TN-001 Calculator → Gỡ cài đặt.
2. Sau khi gỡ xong, cài lại file APK mới vừa tải.

⚠️ Lưu ý: việc gỡ cài đặt sẽ xóa dữ liệu cũ của app (lịch sử tính toán, biến…). Hãy sao lưu trước nếu cần.
